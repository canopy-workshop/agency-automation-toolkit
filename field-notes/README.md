# Field notes

What practitioners saw on real engagements. Dated, attributed, append-only; corrections are new notes. Files go under `<year>/<slug>.md` using the template in `CONTRIBUTING.md`, or arrive through the **Field note** issue template.

Nothing identifying a person, a case, or a record. Agency names only with permission.

A note is promoted into the canon page it touches when two or more engagements cite it, or when it turns into a fixture, a test, or a checklist item. Every canon page lists its inbound notes under **Field notes**.
